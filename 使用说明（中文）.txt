qFlipper · 安卓刷机版  使用说明（中文）
=======================================================

一句话：官方 qFlipper 的全部 Flipper 刷机功能都在，另加了一个「安卓刷机」标签页，
可以认设备、刷 Fastboot 镜像、走高通 9008 烧固件，页面中文英文一键切换。


一、这个文件夹里有什么
-------------------------------------------------------
- qFlipper.exe         主程序（双击这个启动）
- 使用说明（中文）.txt / 使用说明（English）.txt   就是你现在看的这两份
- 补丁（Patch）        离线补丁包：语言切换、刷机 USB 驱动、驱动说明
- 其它 dll / plugins / qml   运行库，别删、别单独拷 exe 出去

装安装包的话会自动建成一样的结构，装完桌面有个 qFlipper 快捷方式。


二、启动与两个面板
-------------------------------------------------------
1. 双击 qFlipper.exe。
2. 标题栏上方有标签：FLIPPER / 安卓刷机（Android）。点一下切换。
3. 两个面板完全分开：Flipper 面板行为和官方一模一样（连 Flipper、刷固件、看文件、遥控），
   安卓面板只管手机，互不干扰。
4. 安卓面板每 1.2 秒自动扫一次 USB，插上手机左侧列表就会自己出现。


三、自动识别四种设备
-------------------------------------------------------
- 普通安卓（ADB）：手机要开「USB 调试」。本页只读型号/端口/模式，不发 adb 命令，
  不会和你电脑上的 adb 抢设备。
- Fastboot 模式：关机后按住「音量下 + 电源」进 bootloader。
- 高通 9008（QDL）：关机后按住音量上下键插 USB，设备管理器里会出现 HS-USB QDLoader 9008。
  本程序读 COM 口，列表里会显示 COMx。
- iPhone / iPad：按苹果 VID 识别，分 DFU / 恢复模式 / 正常模式。
  额外增强：能从 DFU/恢复模式的序列号里读出芯片代号（CPID → A11/A12/A13…），
  直接显示在设备名后面，例如「iPhone / iPad · A12 (CPID 0x8020)」。


四、切换中文 / 英文
-------------------------------------------------------
方法一（临时）：安卓面板右上角有个小圆钮「中文 ⇄ / EN ⇄」，
  点一下整页文字（标签、状态条、提示、日志）全换语言。橙色边框=中文，绿色=英文。
方法二（永久记住）：进「补丁（Patch）」文件夹，双击 切换语言（Switch-Language）.bat，
  会在程序目录建/删 english.flag，重开程序就是英文/中文。再点一次切回来。


五、Fastboot 刷机
-------------------------------------------------------
1. 左侧选中设备（模式显示 Fastboot）。
2. 机型下拉框选你的机型（表里有红米 Note 5/8、K30 Pro、小米 10/11、红魔 5G 等）；
   不在表里就选「其它 / 不校验」。选了档案，连上会自动读 product 代号比对，
   不匹配会红字警告并拒绝刷入，防止刷错机型变砖。
3. 填分区名（boot / recovery / system …），点「选择镜像」挑 .img。
4. 点「刷入镜像」；旁边还有「擦除分区」。

一键重启（四个按钮，就在重启那一行）：
- 桌面 Desktop    → 正常开机进系统
- BOOTLOADER      → 重启回 bootloader
- RECOVERY        → 重启进 recovery
- 9008            → 一键进高通 9008（先试 reboot edl，设备不认再自动试 oem edl）

注意：9008 这个跳转要看机型/bootloader 支不支持，多数骁龙机型可用，
部分厂商锁了这条命令就只能手动按键进 9008。


六、高通 9008 烧录
-------------------------------------------------------
1. 选中设备（模式显示 高通 9008），确认端口有 COMx。
2. 点「选择 rawprogram」选固件包里的 rawprogram0.xml。
3. 点「选择 programmer」选 prog_firehose_ddr.elf（或包里对应的 .elf/.mbn）。
4. 点「开始烧录」。程序握手 → 传 programmer → 按 xml 逐分区写 → 最后自动重启。
   镜像文件要放在 xml 同目录，或 xml 里的相对路径能找到的地方，找不到会立刻停下报错。


七、补丁（Patch）文件夹
-------------------------------------------------------
- 切换语言（Switch-Language）.bat   中英界面永久切换
- 安装驱动（Install-Driver）.bat    右键「以管理员身份运行」，装 Google USB Driver（ADB + Fastboot）
- 驱动说明（Driver-Guide）.txt      高通 9008 / 苹果驱动怎么弄（这两个因授权没打包）
- 补丁说明（Readme）.txt            补丁包简介（中英对照）
- drivers\google-usb\               Google 官方驱动文件（32 位 + 64 位都有）


八、补丁自动下载（程序内）
-------------------------------------------------------
1. 底部状态条右侧有「补丁」按钮，点开小浮层。
2. 填 http/https 直链（例如 https://xxx/patch.zip），点「开始下载」。
3. 文件存到系统「下载」文件夹；同名不覆盖，会自动加 _1、_2 后缀。
4. 只下载保存，不会自动写进设备；下载源自己确认可信，程序不做签名校验。


九、32 位 / 64 位
-------------------------------------------------------
- 安装包是一个，装的时候安装程序自动判断系统位数，只装对应的一套，不会多塞另一套进去。
- 装完的程序目录就是标准的官方样子：qFlipper.exe + 运行库，没有 app32/app64 这类子目录。
- 便携文件夹（qFlipper 目录）是 64 位版；32 位老电脑用安装包装出来的 32 位版本。
- 32 位版功能一致，只是不能处理超大镜像时内存上限更低；另外它没随附 OpenSSL，https 下载会失败。


十、风险与限制（务必看）
-------------------------------------------------------
- 刷错分区/选错固件会变砖。第一次用建议先只刷 boot 试一遍流程。
- 机型校验只比对代号字符串，不校验镜像内容，别拿别的机型镜像硬刷。
- 9008 只支持单个 rawprogram.xml；start_sector 写成 "NUM_DISK_SECTORS-33." 这类表达式的会被拒绝执行。
- 不支持 sparse 镜像、A/B 自动切槽、flashall。
- iOS 只识别不刷机（苹果刷机走 iTunes / 访达 / idevicerestore），不做 SHSH 相关操作。
- 本程序没在真机上跑过完整刷机流程，自己承担风险。
